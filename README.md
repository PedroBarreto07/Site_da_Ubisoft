## Ubisoft Store — UI Clone

> Recriação da interface da Ubisoft Store desenvolvida com HTML, CSS e JavaScript puro.

## Objetivo

Este projeto foi criado com o intuito de praticar:

* Construção de interfaces modernas sem frameworks
* Estilização eficiente utilizando CSS puro com variáveis e boas práticas
* Reprodução fiel de layouts de alto padrão (UI Clone)
* Estruturação semântica de páginas HTML
* Manipulação do DOM com JavaScript vanilla

---

## Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript (Vanilla)

---

## Funcionalidades

* Página inspirada na Ubisoft Store oficial
* Carrossel de jogos com navegação por setas
* Scroll suave com animação de inércia (`scroll-snap`)
* Cards de jogos com imagem, preço original, desconto e preço final
* Badges de edição especial (Gold Edition, From the Ashes Edition)
* Banner Ubisoft+ com efeito hover de expansão
* Header fixo com navegação, lupa de busca e avatar
* Links diretos para as páginas oficiais de cada jogo
* Favicon personalizado com o logo da Ubisoft
* Layout responsivo para diferentes tamanhos de tela

---

## Destaques Técnicos

* Carrossel 100% funcional sem bibliotecas externas
* `scroll-snap-type` para travamento suave entre cards
* `flex-shrink: 0` para manter proporção dos cards no carousel
* Efeito hover com `transform: scale` e `translateY` nos cards e no banner
* CSS Variables para consistência visual em todo o projeto
* Setas do carrossel visíveis apenas no hover com `opacity` transition
* `object-fit: cover` para imagens responsivas sem distorção
* Acessibilidade com `aria-label`, `role` e navegação por teclado
